## 三、逐 skill 详解

### 1. h3-prompt-writing(提示词写作,基础能力)

**核心价值**:H3 视频生成的"通用提示词引擎",所有风格 skill 底层都依赖它把需求改写成 H3 结构化提示词。

- 支持 **5 种 H3 生成模式**:`T2VA`(文生视频)、`I2VA`(图生视频)、`FL2VA`(首尾帧)、`L2VA`(参考视频+文本)、`Ref2VA`(完整参考)
- 将多模态请求改写为 H3 提示词结构:`integrated_multimodal_description`(多模态描述)、`overall_soundscape`(整体声景)、`non_diegetic_music`(非剧情音乐)
- **对齐关键帧**、定义**图片/视频/音频参考标签**
- 附提示词参考文档:`references/base-en.txt`(基础文本/关键帧模式)、`references/ref-en.txt`(完整参考模式)

### 2. 3d-animation-short-generator(3D 动画短片)

**功能**:把一句故事创意转化为**完整的风格化 3D 动画短片**。

**工作流**(严格按顺序):
1. **项目简报** → 2. **故事大纲(守门)** → 3. **角色卡** → 4. **无人物场景卡** → 5. **六列标准镜头信息表**(镜头自检门强制)→ 6. **单文本分镜**(默认)或**多宫格铅笔分镜**(可选)→ 7. **视频模型选择** → 8. **单镜头生成** → 9. **全片拼接** → 10. **BGM 匹配** → 11. **最终复查**

**特性**:全局视觉风格锁,保证角色一致性、场景连续性、节奏明确、音画配合。
**适用**:剧情动画短片、纪念短片、品牌故事、社交媒体。
**不适用**:单张图片、简单修图、真人写实视频、单一独立镜头。

### 3. brand-promo-video-generator(品牌宣传短片)

**功能**:为品牌/产品/网站/App/小店/个人项目制作宣传短片。

**输入要求**:LOGO、产品图、界面截图、官网链接等**可核验素材**;确认时长、画幅、受众、推广重点。
**工作流**:素材确认简报 → 品牌事实表 → 素材来源清单 → 选择故事脊柱 → 规划精确节拍 → 导演动效语言 → 生成前硬确认 → 生成 Hub 资产(图像/视频/旁白/音乐)→ 交付前验证 → 交付。
**特性**:可用 `webfetch`/`hub` 系列工具;突出产品功能、使用场景、行动号召。
**适用**:新品发布、官网展示、社交媒体推广。
**不适用**:无授权素材仿造真实品牌标识、虚构产品功能、长篇剧情影片。

### 4. co-op-game-intro-generator(双人游戏开场视频)

**功能**:制作**双人合作游戏主菜单/开场动画**。

**输入要求**:两位玩家名称、游戏名称、目标视觉风格;可上传角色参考图。
**工作流**:询问风格 → 收集玩家与游戏信息 → 生成 GPT 首图提示词 → 生成**确认首图**(固定菜单布局,色彩/按钮/图标/字体联动)→ 等待用户确认 → 回填视频 prompt 并用 **MiniMax H3 生成** → 常见失败修正。
**输出**:双人角色 + 玩家信息卡 + 主菜单交互动效的开场视频。
**适用**:合作游戏概念展示、角色化菜单、社交内容。
**不适用**:完整可玩游戏开发、复杂多页面 UI、精确品牌标识复刻、无角色通用片头。

### 5. handdrawn-live-video-generator(手绘 × 实拍融合)

**功能**:制作**手绘发光动画与实拍空间融合**的 15 秒短片。

**输入要求**:场景创意、接触对象或手部动作、情绪氛围、可选风格限制。
**工作流**:把意图理解为同语种约束 → 每次重新发明创意内容 → 输出**15 秒 16:9**视频提示词(用户语言)→ 建议用 **MiniMax H3 生成** → 检查接触真实感、镜头延迟、粗糙发光笔触、非恐怖调性。
**特性**:明确"手绘动画真实接触实物"的触碰关系;慢半拍手持追拍镜头语言。
**适用**:单场景创意短片、手绘实拍融合视频。
**不适用**:精致 CG、恐怖跳吓、毛绒角色、多场景剪辑。

### 6. minimalist-product-ad-generator(极简产品广告)

**功能**:上传一张产品图,按 **Apple 风**制作一条高质感产品广告短片。

**工作流**:素材检查与产品事实摘要 → 确认制作简报 → 选择产品叙事脊柱 → 导演动效语言 → 生成/确认 **Apple 风英文文案** → 生成三张独立产品锚定照片 → 精确节拍与文字分镜表 → 生成干净、有节奏、产品质感突出的短片。
**适用**:电商商品、小品牌新品、潮玩、食品、数码配件。
**不适用**:KOC 口播、普通剪辑、复杂屏幕演示。

### 7. mv-subtitle-skill-confirmed(音乐 MV 歌词字幕)

**功能**:制作**带歌词贴字的 AI MV 或情绪短片**。

**输入要求**:音乐、歌词、参考图、角色、字体方向、情绪意图或发布平台。
**工作流**:分析节拍与人声时序 → 区分人物/场景/文字参考 → 设计**随节奏变化的空间字幕** → 拆解长视频为可衔接镜头 → 审查提示词并路由 H3 等视频生成工具。
**输出**:MV 概念、分镜提示词、歌词文字方案、拼接建议。
**适用**:风格化音乐视觉、动态字幕 MV(Trap/Gospel hip-hop/Dark-pop/Cyber-grunge 等)。
**不适用**:普通字幕校对、照搬已有 IP、完全手工后期剪辑。

### 8. paper-collage-explainer-generator(纸拼贴讲解动画)

**功能**:用**触感纸拼贴**语言表现口播句、知识点、观点或抽象主题。

**输入要求**:短文案、故事节点或核心概念;可补充画幅、时长、色调和音频需求。
**工作流**:解析输入 → Gate 1 制作方案确认(Brief/视觉隐喻/脚本节奏轨/分镜)→ 生成并确认**半调纸拼贴静帧** → 制作停格动画(纸片滑入/弹入/轻敲/压平/摩擦声)→ 按需合成完整讲解视频。
**音频策略**:默认**保留拼贴音效**,不主动添加 BGM/旁白/字幕。
**适用**:知识讲解、观点表达、故事配画、社交 B-roll。
**不适用**:真人口播广告、精确可编辑图层、复杂文字排版、仅输出提示词。

### 9. papercraft-stop-motion-explainer(纸艺定格科普)

**功能**:用**手工纸艺**视觉讲解科学、教育或泛知识内容。

**输入要求**:主题、核心知识点或原始材料;可指定受众、时长、画幅、交付类型。
**工作流**:提炼学习目标与视觉隐喻 → 提出创意方向 → 设计**纸偶角色、分层纸雕布景、道具资产** → 制作预览概念、图像与视频提示词 → 规划分镜、运镜、转场和声音 → 阶段确认与审核清单控制质量。
**输出**:可直接投入制作的**纸艺定格科普视频创作包**;或按需交付单图、系列图、短视频提示词、分镜。
**适用**:纸雕、剪纸、立体书、微缩定格讲解。
**不适用**:普通二维卡通、线稿涂鸦、真人写实视频、无纸艺质感的标准科普。

## 四、通用说明

- 8 个风格 skill 均**默认走 MiniMax H3** 生成视频;`h3-prompt-writing` 是它们改写提示词的底层能力
- 各 skill 均含 `references/`(提示词模板)与 `meta.yaml`(触发词),触发词见各 `SKILL.cn.md` 的 `trigger-words`
- 需要与 RunningHub / ComfyUI 本地 H3 工作流联动时,可配合 `webs/RunningHub`、`refs/minimax-h3-guide` 资料使用
