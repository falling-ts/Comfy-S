# MiniMax H3 提示词格式调研(采样器输入 · 秒数机制 · Ref2VA 参考格式)

> 调研日期:2026-08-11
> 范围:官方 MiniMax H3 采样器节点源码(`ComfyUI/comfy_extras/nodes_minimax_h3.py`)、官方 `h3-prompt-writing` skill(含 `base-en.txt`/`ref-en.txt` 提示词指南)、MiniMax-H3 官方仓库 README(在线确认)、8 个风格 skill 的提示词模板

## 一、官方核心采样器节点(ComfyUI 本地)

本地 `ComfyUI/comfy_extras/nodes_minimax_h3.py` 提供两个采样/条件节点:

### 1. `MiniMaxH3ImageToVideo`(T2VA / FL2VA)

| 输入 | 类型 | 说明 |
|------|------|------|
| `clip` / `vae` | CLIP / VAE | 文本编码器 / 视频 VAE |
| **`prompt`** | STRING(multiline) | 生成提示词 |
| `width` / `height` | INT | 默认 1344×768 |
| **`length`** | INT | **帧数 @24fps**,默认 124(≈5 秒),min 5 / max 3600,step 17(模型的 17k+5 网格);训练区间 ~124–362(即约 5–15 秒) |
| `first_frame` / `last_frame` | IMAGE(可选) | 首帧 / 尾帧 → 分别构成 I2VA / FL2VA |

> docstring: *"t2va and fl2va: prompt (+ optional first/last keyframes) → conditioning + AV latent"*。L2VA(仅尾帧收敛)复用本节点 last_frame 输入。

### 2. `MiniMaxH3ReferenceToVideo`(Ref2VA,参考生视频)

| 输入 | 类型 | 说明 |
|------|------|------|
| `clip` / `vae` / `audio_vae` | — | 文本编码器 / 视频 VAE / 音频 VAE |
| **`prompt`** | STRING(multiline) | 提示词,**用 `<Picture i>` / `<Video k>` / `<Audio j>` 标签引用参考** |
| `width` / `height` / `length` | INT | 同左 |
| `ref_images` | IMAGE(≤9) | 参考图(短边超 2048 下采样) |
| `ref_videos` | VIDEO(≤3) | 参考视频(24fps,2–15 秒,≥5 帧) |
| `ref_video_audios` | AUDIO(≤3) | 与 `ref_video_N` 同编号配对的音轨 |
| `ref_audios` | AUDIO(≤3) | 独立参考音频 |

> 参考呈现顺序固定:**images → videos(每段 soundtrack 的 `<Audio j>` 标签紧贴其 `<Video k>` 前)→ standalone audio**;序号按类型各自 1-based。prompt 需用同一标签引用(节点 description:*"Use the same tags when prompting"*)。

## 二、提示格式(基础模式 T2VA / I2VA / FL2VA / L2VA)

官方 `h3-prompt-writing/references/base-en.txt` 定义:**提示词 = 第一部分(对齐指令)+ 第二部分(三核心字段)**。

### 2.1 第一部分:对齐指令(Instruction)

| 模式 | 指令文本(固定首行) |
|------|--------------------|
| **T2VA** | 无对齐指令,直接开始三核心字段 |
| **I2VA** | `For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.` |
| **FL2VA** | `How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.` |
| **L2VA** | `How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.` |

> `S.SS` = 有效视频时长,格式化为**两位小数秒**(如 `5.00`)。指令后空一行再接核心字段。

### 2.2 第二部分:三核心字段

```text
integrated_multimodal_description: [Shot 1] ...
overall_soundscape: ...
non_diegetic_music: ...
```

| 字段 | 内容 |
|------|------|
| `integrated_multimodal_description` | 按时间线描述视觉/动作/镜头/说话/对话/唱歌/剧情音频,以 `[Shot N]` 分段 |
| `overall_soundscape` | 全片环境声、物理动作声、非语言人声总结 |
| `non_diegetic_music` | 角色听不到、只有观众听到的背景音乐 |

### 2.3 镜头(Shot)与秒数时间戳

- **第一个镜头不加时间戳**;后续镜头用**严格递增的切点时间**,格式 `At 00:SS.mmm`(**分:秒.毫秒**,如 `At 00:03.500` 表示第 3.5 秒):

```text
[Shot 1] Live-action, cinematic, a medium-wide shot frames...
[Shot 2] At 00:03.500, the camera cuts to...
```

- **镜头运动**:运动类型(推/拉/摇/移/升降/环绕/跟拍/静止/抖动/POV/滚动)+ 幅度(`with small/large amplitude`)+ 速度(`at slow speed/fast speed`),写成句内自然英文。
- **说话人**:稳定 ID `(S1)`/`(S2)`;首次出现建立身份(类型/年龄/性别/音色/语速/口音);对话放 `<d>` 内,保留原文不翻译。
- **风格**:镜头开头给整体风格,如 `Cinematic` / `live-action` / `2D-animated` / `3D CG` / `claymation` / `watercolor` / `vintage film`。

## 三、秒数机制(是否含秒数、如何设置)

### 结论:提示词里含秒数(时间标记),但实际生成时长由采样器 `length`(帧数)决定

| 层面 | 秒数如何出现 | 控制方 |
|------|-------------|--------|
| **实际时长** | `length` 帧数 @24fps,默认 124 帧 ≈ 5 秒 | **采样器节点**(不是 prompt) |
| **对齐指令** | `S.SS`(两位小数秒,如 `0.00` / `5.00`) | prompt(参考帧对齐标记) |
| **镜头切换** | `At 00:SS.mmm`(分:秒.毫秒) | prompt(切点时间) |
| **时间段(风格 skill)** | `0-3 秒` / `3-6 秒` / `6-10 秒`…(如 handdrawn 15 秒模板) | prompt(分段描述) |

- **官方时长范围:4–15 秒**(MiniMax-H3 README `Output duration`)。本地节点训练区间 ~124–362 帧(约 5–15 秒)。
- **实践**:写 prompt 的时间戳/时间段必须与 `length` 对应的实际时长一致(如 length=124 帧≈5 秒,prompt 内镜头切点要落在 0–5 秒内);若用 15 秒模板,`length` 需设 ~360 帧(15s × 24fps)。
- 风格 skill 示例(`handdrawn-live-video-generator`):15 秒 16:9 prompt,用 `0-3 秒`、`3-6 秒`、`6-10 秒`、`10-13 秒`、`13-15 秒` 分段;`co-op-game-intro-generator` 模板用 `[0秒–2秒]`、`[2秒–X秒]` 时间段标题。

## 四、参考生视频(Ref2VA)参考文本格式

官方 `h3-prompt-writing/references/ref-en.txt` 定义 **六段式输出**:

| 段 | 作用 |
|----|------|
| `subject_definitions` | 定义每块被引用内容及其标签 |
| `summary` | 总结任务类型、目标视频、主要参考关系 |
| `retention_analysis` | 描述参考内容如何被保留/转移/复用 |
| `detailed_description` | 按播放顺序描述视觉/动作/镜头/声音/对话 |
| `overall_soundscape` | 环境声与物理声音 |
| `non_diegetic_music` | 仅观众可闻的背景音乐 |

### 4.1 参考标签(四种)

| 标签 | 含义 |
|------|------|
| `<Subject N>` | 从参考资产中抽象出的**可复用/可修改的可见内容**(人物/动物/物体/场景/服装/道具/界面/风格/动作/表情/姿态) |
| `<Picture N>` | 参考**图**,用作目标帧/关键帧/首尾帧/构图锚点/分镜参考 |
| `<Video N>` | 参考**视频**,提供剪辑源、续接起点、或整段时间结构(运镜/剪辑/节奏) |
| `<Audio N>` | 参考**音频**(复制信号 / 引用 BGM 风格 / 说话人音色 / 节拍节奏) |

> 标签一经分配,在六个段落中含义保持一致。一个 `<Subject N>` 可来自多个资产(如"外观来自 `<Picture 1>`、走路动作来自 `<Video 1>`");图片若只用于定义某 subject,不单列 `<Picture N>` 条目。

### 4.2 参考数量限制(官方 README)

| 类型 | 上限 |
|------|------|
| 参考图 `<Picture>` | ≤ 9 |
| 参考视频 `<Video>` | ≤ 3 段(每段 2–15 秒,总时长 ≤ 15 秒) |
| 参考音频 `<Audio>` | ≤ 3 段(每段 2–15 秒,**须伴随图/视频输入,不能单独作为输入**) |
| 混合输入总数 | ≤ 12 个文件 |

## 五、实践建议(参照官方 skill + 网络)

1. **提示词规范**:严格按 `base-en.txt`(基础模式)/ `ref-en.txt`(Ref2VA)写,保留字段名、段落顺序、标签、时间标记写法(大小写一致)。
2. **时长对齐**:先定目标秒数 → 换算帧数(`秒数 × 24`)填 `length` → prompt 内时间戳/时间段与之一致。
3. **参考标签**:Ref2VA 的 prompt 用 `<Picture i>`/`<Video k>`/`<Audio j>` 引用,与节点 `ref_images`/`ref_videos`/`ref_audios` 的输入顺序一一对应。
4. **Context-IR 提示**:官方强烈建议对复杂多模态输入做 `H3-Context-IR`(Context Intermediate Representation)预处理(把指令解析、跨模态关联、时间理解、逻辑推理转成 H3 易懂形式)。开源版不含 Context-IR,可用官方 API 复现,或按 *Prompting Guidance* 自建——**本地 ComfyUI 直接按节点 prompt 写即可**,复杂多参考时参考 skill 的六段式提升效果。
5. **本地可用**:`h3-prompt-writing` 已安装到 `.agents/skills/`(见《MiniMax-H3-Skills-使用说明》),可直接调用让 WorkBuddy 帮你把需求改写成符合上述规范的 H3 提示词。

## 七、常用标记速查(Shot / S1 / `<d>` / `<Subject N>`)

### 7.1 Shot(镜头)

- `[Shot 1]` = 视频第 1 个镜头,开场镜头,**不加时间戳**。
- 视频由多个镜头组成;后续镜头用递增编号 + 精确切点时间:`[Shot 2] At 00:03.500`(分:秒.毫秒)。
- 每个镜头描述一段连续的画面与声音;切换方式可选 cut / cross-dissolve / fade 等。

### 7.2 (S1)/(S2)(说话者编号)

- **Speaker ID**。开口说话、演唱或发出人声的主体获得稳定编号。
- 首次出现时附身份上下文(角色类型/年龄/性别/音色/语速/口音),之后跨镜头复用同一 ID,不得重编。
- 两人/多人齐声用复合 ID `(S1,S2)`;从头不出声的角色不分配 ID。
- 旁白用 `says in an off-screen voiceover`,并注明画面角色嘴唇闭合。

### 7.3 `<d>...</d>`(对白内容)

- `<d>` 内**只放语言标签 + 原话**:`<d>[English] I get off at the next station.</d>`
- 原话逐字保留、不翻译、不改写;语言标签标明语种。
- 说话者的身份描述、动作、语态一律写在 `<d>` 之外。
- 对白跨镜头用 `<scenetrans>` + 连续性短语;说话被视频结尾截断用 `<cutoff>`。

### 7.4 `<Subject N>` 与四类参考标签

| 标签 | 层级 | 含义 | 例子 |
|------|------|------|------|
| `<Subject N>` | **内容层** | 被复用的**内容单元**(人物/动物/物体/场景/服装/道具/界面/风格/动作/表情/姿态) | `<Subject 1> 是 <Picture 1> 中那位黑发女性` |
| `<Picture N>` | **素材层** | 充当**帧锚点**的图片(首帧/尾帧/关键帧/构图锚点/分镜参考) | `<Picture 2> 是 [Shot 3] 的首帧` |
| `<Video N>` | **素材层** | 剪辑来源 / 续写起点 / 参考节奏的**源视频** | `<Video 1> 提供行走动作与手持运镜` |
| `<Audio N>` | **素材层** | 被复制或引用的**音频**(信号/音色/BGM 风格/节拍) | `<Audio 1> 是 <Subject 1> (S1) 的音色参考` |

### 7.5 为什么只靠 Picture/Video/Audio 不够,必须有 Subject

**`Picture/Video/Audio` 是"素材文件"层,`Subject` 是"内容"层。** 一个素材文件里通常包含多个可复用内容:

- 一张图里同时有人物、场景、服装 → 分别定义 `<Subject 1>` 人物、`<Subject 2>` 场景、`<Subject 3>` 服装,独立追踪各自要保留的特征;
- 一个参考视频的动作与运镜是不同内容 → 可拆成不同 Subject,或由 `<Video N>` 整体提供结构;
- `Picture/Video/Audio` 回答"来自哪个文件",`Subject` 回答"文件里哪部分内容要复用、保留什么特征",二者配合才能精确指定复用什么、怎么复用。

> 一个 `<Subject N>` 可来自多个素材(如"外观来自 `<Picture 1>`、走路动作来自 `<Video 1>`");标签一经分配,在 Ref2VA 六个段落中含义保持一致,不得换义或遗漏。
