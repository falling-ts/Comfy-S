# 视频/音频分析工具链(读产物)

> 场景: 任何"视频/音频生成完了, 要确认它到底生成了什么"的场合。
> 本机实测通过(2026-09-13, 样本 = 0043 关键帧视频 `ComfyUI_temp_amsji_00001_.mp4` + 其音轨)。
> ⚠️ 根 `scripts\` 临时目录已于 2026-10-11 移除。**本文档内嵌的源码才是唯一长期记录**; 需要时把下方源码块经 stdin 就地交给解释器跑即可(`.venv\Scripts\python.exe - <<'PY' ... PY`), 不落盘、不需要新建目录(§10、§11)。

## 0. 总原则

1. **`status: success` ≠ 产物正确。** 必须真读产物: 画面抽帧后 `read_image` 逐张看; 音频转成文字/特征/频谱图后再判断。
2. **AI 没有听觉, 视觉也只有一个通道**: 唯一"看"的手段是 `read_image`(PNG/JPEG/WebP/GIF)。视频与音频本身无法直接读, **必须先落成帧图 / 频谱图**。
3. **图与数字必须一起看。** 声学数字会骗人 —— 实测两个反例: 纯音乐时 `pyin` 把贝斯基频当人声 F0(判成"男声"); 单看"谱平坦度 0.0141 很低"会误判"没有宽带底噪", 而频谱图上明明有一层均匀的宽带层。
4. **串行执行, 不要并发。** SenseVoice 要加载 936 MB 权重, 与 ComfyUI 抢同一张 8 GB 卡; 跑音频分析前确认 ComfyUI 空闲(或接受排队)。

## 1. 链路总览

```text
定位产物 ──► 探针(ffprobe) ──┬─► 画面: 抽帧/联络表 ──► read_image 逐张看

```

## 3. 第 1 步: 探针(先量, 再看)

```bash
ffprobe -v error -print_format json -show_format -show_streams <文件>
ffmpeg -i <文件>            # 人读版: 时长/分辨率/fps/码率/有无音轨
```

必须核对的量: **视频** 编码/宽高/fps/总帧数/像素格式; **音频** 编码/采样率/声道/时长; **有没有音轨**(H3 是带音频的模型, 没音轨通常是提示词 `overall_soundscape` 段没写对)。

时长自检: `总帧数 ÷ fps = 时长`。例: H3 固定 24 fps, `362 帧 ÷ 24 = 15.0833s` = `duration_s` ✓; 音轨 `15.075s` 比视频短 ~8 ms 属正常(编码器帧对齐差)。

## 4. 第 2 步: 画面(抽帧 → 联络表 → 看图)

```bash
# 精确抽单帧(-ss 放 -i 之后: 逐帧解码, 准但慢; 短片首选)
ffmpeg -y -i in.mp4 -ss 11.000 -frames:v 1 f011.00s.png
# 快速定位(-ss 放 -i 之前: 关键帧对齐, 快但可能偏几帧; 长片扫查用)
ffmpeg -y -ss 11.000 -i in.mp4 -frames:v 1 f011.00s.png
# 联络表: 每 N 秒一格拼成 CxR(整片一眼看完, 找"哪一段开始不对"最高效)
ffmpeg -y -i in.mp4 -vf "fps=1/2,scale=640:-1,tile=4x3" -frames:v 1 grid.png
```

- 抽帧策略: 先按锚点秒数抽(`0 / 中点 / 末帧` 或提示词里 `At 00:07.500` 那些时间点), 发现异常段再用 `--every` 批量细扫。
- **判读要点**: 锚点图里的主体在不在、数量/位置/颜色对不对、有没有"被文字描述替换掉"(实测: 提示词把桌面主体写成"摊开的手稿", 视频中段笔记本就变成了摊开的书)。
- 抽帧落盘目录建议系统临时目录(如 `%TEMP%\video-<名>\`), 文件名带秒数便于回溯; 不要写进项目树。

## 5. 第 3 步: 音频

### 5.1 命令

```bash

ffmpeg -y -v error -i in.mp4 -ac 1 -ar 16000 mono16k.wav
# 三件套(转写/情绪/事件 + 声学特征 + 频谱图) —— 见 §10.B
# 源码经 stdin 就地执行(不落盘), 见 §11
```

### 5.2 SenseVoiceSmall: 转写 + 情感 + 事件 + 语种(全离线)

- 权重: `models\TTS\SenseVoiceSmall\`(`model.pt` 936 MB + `chn_jpn_yue_eng_ko_spectok.bpe.model` + `config.yaml`), 由 `funasr` 1.4.2 加载; 传**本地路径** + `disable_update=True` ⇒ 不发网络请求。
- 输出是"富文本标签 + 文本": `<|语种|><|情绪|><|事件|><|withitn|>文本`。
  - 语种: `zh / en / ja / ko / yue`
  - 情绪(SER): `HAPPY / SAD / ANGRY / NEUTRAL / EMO_UNKNOWN`
  - 事件(AED): `Speech / BGM / Applause / Laughter / Cry / Cough / Sneeze / Breath` 等
  - `rich_transcription_postprocess()` 会把事件/情绪换成 emoji(如 `BGM → 🎼`), **所以原始标签也要打印**(否则丢信息)。
- **纯音乐时的语种/情绪判定无意义**(实测输出 `<|en|><|EMO_UNKNOWN|><|BGM|>`, 那个 `en` 是噪声, 不要当结论)。
- AED 标签集里**没有**"雨声/键盘声/翻页声"这类细粒度环境音 ⇒ 它**标不出环境音效缺不缺**, 那要靠声学特征 + 频谱图判。
- 性能实测: 加载 ~4 s, 15 s 音频 `rtf≈0.095`(GPU)。

### 5.3 声学特征怎么读(librosa / pyloudnorm / torchaudio)

| 特征 | 读法 |
|---|---|
| 整体响度(LUFS) | `pyloudnorm.integrated_loudness`; 实测 -26.4 LUFS = 偏安静的对白/环境级 |
| 有声占比 / 静音段 | RMS 包络 > 峰值 5% 为"有声"; 连续 <阈值 且 >0.3 s 记静音段(查开头留白/结尾截断) |
| 节奏 BPM | `librosa.beat.beat_track`; **有稳定 BPM ⇒ 有节奏性配乐**(实测 133.9 BPM), 雨声/写字声不会有固定脉冲 |
| 频谱质心 | 大 = 明亮/尖锐, 小 = 低沉/温暖(实测 1.4 kHz 偏中低) |
| 谱平坦度 | 大 = 噪声性(雨/风/气声), 小 = 谐波性(乐音/浊音); **但宽带层被强低频淹没时会偏低, 别单独下结论** |
| ZCR | 高 = 摩擦/噪声成分多 |
| MFCC 1~3 | 音色包络, 用于同类声音的对比(不是绝对值判断) |
| **F0(基频)** | `librosa.pyin(fmin=60, fmax=500)` → 中位数/范围/标准差; **只对"有人声的片段"有效** |

**性别判定的正确用法(启发式, 不是结论)**: 先确认 AED = `Speech`(有人声), 再对**语音段**取 F0 中位数: `<155 Hz → 男声倾向`, `>200 Hz → 女声倾向`, 之间 → 不确定。**纯音乐/歌唱下该判定无效**(实测把 74~87 Hz 的贝斯基频判成了"男声")。

### 5.4 频谱图 / 波形图(把声音变成我能看的图)

```bash
ffmpeg -y -i in.mp4 -lavfi "showspectrumpic=s=1024x512:legend=disabled" spec.png
ffmpeg -y -i in.mp4 -lavfi "showwavespic=s=1024x256:colors=white" wave.png
```

判读: 底部亮带 = 低频强(鼓/贝斯); 等距竖线 = 规律起音(节拍); 横线 = 持续音的谐波; 均匀颗粒填充 = 宽带噪声层(雨/混响)。其它可用 ffmpeg 音频分析滤镜: `ebur128`(响度)、`astats`(帧统计)、`silencedetect`(静音切点)。

## 6. 第 4 步: 与提示词/锚点交叉印证

1. 取"进编码器的文本": 工作流节点状态 `widgets_values[0].selected.values['视频提示词']`(md 表里的 `<br>` 到运行时已变成真换行), 或用 `scripts\workflow-to-prompt.py` 重建 API 图。
2. 逐段对照: `overall_soundscape`(环境音) / `non_diegetic_music`(配乐) / 每个 `[Shot n]` 的画面描述 / `<Picture n>` 锚点构图。
3. 实测踩到的真问题(可作范例):
   - 提示词 `overall_soundscape` 要的是"持续中雨声 + 笔尖划过纸面的沙沙声 + 偶尔翻页", `non_diegetic_music` 要的是"低沉克制的大提琴单音长音, 音量极轻, 12.00 秒后淡出" ⇒ 实际音轨 AED=`BGM`、librosa **133.9 BPM**(频谱图上是等距的规律起音竖线)、强低频、-26.45 LUFS, **与"极轻的单音长音"明显不符**(其中是否真有雨声层无法由特征断定, 主观听感仍需人耳确认)。
   - ⚠️ **读声音段必须整段读全, 不要用关键词 grep**: 第一次读该提示词时用 `(音乐|声|雨|音效)` 过滤, 而 `non_diegetic_music` 正文里既没有"音乐"也没有"声", 于是整行漏读、误判成"该段留空"(结论因此错了)。正确做法: 定位到 `overall_soundscape` 行, 从它开始**连续打印若干行**。
   - 提示词 3 处把桌面主体写成"摊开的手稿"、而中段锚点是**没有桌子**的窗玻璃特写 ⇒ 帧 181~360 无锚点区间里, 模型照文字把笔记本画成了摊开的书, 尾帧锚点才把它拉回来。

## 7. 能力边界(别承诺做不到的)

| 需求 | 能否 | 说明 |
|---|---|---|
| 说了什么(转写) | ✅ | SenseVoice(中/英/日/韩/粤, 带时间戳); 需逐词精度可另装 faster-whisper 权重(库已装) |
| 情绪 | ✅ 有人声时 | SenseVoice SER 四类 + unknown |
| 有没有人声/是不是音乐 | ✅ | AED 标签 `Speech` / `BGM` |
| 响度/节奏/音域/静音/结构 | ✅ | librosa + pyloudnorm + ffmpeg |
| 角色性别 | ⚠️ 启发式 | 仅"有人声"时按 F0 中位数判; 歌唱/音乐不可用; 要准需声纹模型 |
| 音色(低沉/明亮/沙哑/气声) | ⚠️ 客观化 | 靠 F0/质心/平坦度/MFCC/ZCR 组合描述, 不能"像谁" |
| 说话人分离(几个人、谁在说) | ❌ 只能粗分 | 本机无 diarization 权重; 只能按 F0 聚成"两条声线" |
| 这是哪首歌 / 用了什么曲库 | ❌ | 需联网指纹库(chromaprint+AcoustID / Shazam API), 本机无; AI 生成的 BGM 库内也查不到 |
| 认人(像哪个配音演员) | ❌ | 需声纹库比对(pyannote / 3D-Speaker), 未装 |
| 主观听感(自然不自然、口音怪不怪) | ❌ | **AI 没有听觉**, 必须人耳确认 |

可升级项: faster-whisper 权重(逐词时间戳/更强中文, ~0.5–1.5 GB) · pyannote 或 3D-Speaker(性别+说话人分离, 100 MB–1 GB) · CLAP/AST(AudioSet)(音乐风格、雨/键盘/脚步等环境声标签, ~600 MB) · chromaprint `fpcalc`(曲目指纹)。

## 8. 已知坑

- **脚本"失败"其实是 exit 1**: torch 的 `pynvml` FutureWarning 走 stderr, 被 PowerShell 当 `NativeCommandError`。过滤: `| Select-String -NotMatch 'pynvml|FutureWarning|CategoryInfo|FullyQualifiedErrorId|At line|^\s*\+'`; 判成功看**业务输出**而不是退出码。
- **`funasr` 别用 `device="cuda"` 硬碰**: ComfyUI 正占显存时可能 OOM ⇒ 改 `device="cpu"`(15 s 音频也就几秒)。
- **抽帧时间点别超时长**: `-ss` 超过 `duration` 时 ffmpeg 退出码仍是 0 但**不生成文件**(末帧用 `时长 - 1/fps`)。
- **默认参数不要照抄到长视频**: `--every` 批量抽帧 + `tile` 联络表在长片上会非常慢, 先抽关键点。
- `read_image` 只认图: 想"看"音频必须先生成频谱图/波形图。
- **读提示词的声音段要整段打印, 不要关键词 grep**(实测漏读 `non_diegetic_music` 正文并得出错误结论, 见 §6)。

## 9. 与技能的关系

`comfyui-workflow-runner` 技能规定的是"跑工作流 + 探针 + 抽帧"的最小子集(其 `SKILL.md` 里给的是 `ffmpeg -i` 与 `tile` 联络表命令, 脚本只有 `workflow-to-prompt.py` 等, **没有抽帧脚本**)。本文档是它的超集: 补齐了可复用脚本、音频全链、能力边界与坑。跑工作流仍走技能; 读产物按本文档。

## 10. 源码(唯一长期记录)

### A. `video-analyze.py`(源码内嵌, 经 stdin 就地执行)

```python
"""视频产物分析: 探针 → 抽帧 → 联络表 → 音频分析(可选)。

用法:
    python - < <此文件§10.A 的源码>   # 或经 stdin: .venv\Scripts\python.exe - <<'PY' ... PY
    # 参数: <视频> [--at 0,7.5,15] [--every 1] [--grid 4x3]
                                    [--width 640] [--out 目录] [--fast] [--audio]

  --at     指定秒数列表抽帧(精确 seek); 默认取 首帧/中点/末帧
  --every  每 N 秒抽一帧(批量扫全片)
  --grid   额外输出一张 CxR 联络表(默认 4x3, 每 2 秒一格)
  --fast   -ss 放到 -i 之前(关键帧对齐, 快但可能偏几帧)
  --audio  顺带调用 audio-analyze.py(转写/情绪/事件 + 声学特征 + 频谱图)

产物全部落在 --out(默认 scripts\\tmp-video\\<视频名>\\), 打印绝对路径供 read_image 直接读。
"""

import argparse
import json
import pathlib
import subprocess
import sys
import tempfile

DEFAULT_OUT = pathlib.Path(tempfile.gettempdir()) / "video-analyze"


def probe(path: pathlib.Path) -> dict:
    """ffprobe 探容器与流(视频: 宽高/fps/帧数; 音频: 采样率/声道)。"""
    out = subprocess.run(
        ["ffprobe", "-v", "error", "-print_format", "json", "-show_format", "-show_streams", str(path)],
        capture_output=True, text=True, encoding="utf-8",
    ).stdout
    info = json.loads(out or "{}")
    fmt = info.get("format", {})
    res = {"file": path.name, "size_B": int(fmt.get("size") or 0),
           "format": fmt.get("format_name"), "duration_s": float(fmt.get("duration") or 0),
           "bit_rate": int(fmt.get("bit_rate") or 0), "video": None, "audio": None}
    for st in info.get("streams", []):
        if st.get("codec_type") == "video" and res["video"] is None:
            num, _, den = (st.get("avg_frame_rate") or "0/1").partition("/")
            fps = float(num) / float(den) if float(den or 0) else 0.0
            res["video"] = {"codec": st.get("codec_name"), "wh": f"{st.get('width')}x{st.get('height')}",
                            "fps": round(fps, 4), "nb_frames": st.get("nb_frames"), "pix_fmt": st.get("pix_fmt")}
        elif st.get("codec_type") == "audio" and res["audio"] is None:
            res["audio"] = {"codec": st.get("codec_name"), "sample_rate": st.get("sample_rate"),
                            "channels": st.get("channels"), "duration_s": st.get("duration")}
    return res


def grab(src: pathlib.Path, t: float, outdir: pathlib.Path, fast: bool = False) -> pathlib.Path:
    """抽单帧。默认精确 seek(-ss 在 -i 之后, 逐帧解码); fast=True 用输入 seek。"""
    dst = outdir / f"f{t:06.2f}s.png"
    seek = ["-ss", f"{t:.3f}"] if fast else []
    cmd = ["ffmpeg", "-y", "-v", "error", *seek, "-i", str(src)]
    if not fast:
        cmd += ["-ss", f"{t:.3f}"]
    cmd += ["-frames:v", "1", str(dst)]
    subprocess.run(cmd, check=True)
    return dst


def contact_sheet(src: pathlib.Path, outdir: pathlib.Path, every: float, cols: int, rows: int, width: int) -> pathlib.Path:
    """按 fps=1/every 抽帧拼成 CxR 联络表(整片一眼看完)。"""
    dst = outdir / f"grid-{cols}x{rows}-{every:g}s.png"
    vf = f"fps=1/{every:g},scale={width}:-1,tile={cols}x{rows}"
    subprocess.run(["ffmpeg", "-y", "-v", "error", "-i", str(src), "-vf", vf, "-frames:v", "1", str(dst)], check=True)
    return dst


def run_audio(src: pathlib.Path) -> None:
    """联动音频分析(同一支路)。

    注意: 经 stdin 就地执行时不存在同目录的 audio-analyze.py 文件, 故本处只打印
    提示, 不自动 subprocess 调用; 需要音频分析请单独跑 §10.B。
    """
    print(f"[音频] 请对 {src} 单独跑 §10.B 的 audio-analyze 源码(--asr --features --plots)")


def main() -> int:
    sys.stdout.reconfigure(encoding="utf-8")
    ap = argparse.ArgumentParser()
    ap.add_argument("video", type=pathlib.Path)
    ap.add_argument("--at", default="")
    ap.add_argument("--every", type=float, default=0.0)
    ap.add_argument("--grid", default="4x3")
    ap.add_argument("--width", type=int, default=640)
    ap.add_argument("--out", type=pathlib.Path, default=None)
    ap.add_argument("--fast", action="store_true")
    ap.add_argument("--audio", action="store_true")
    a = ap.parse_args()
    if not a.video.is_file():
        print(f"找不到文件: {a.video}")
        return 2

    outdir = a.out or (DEFAULT_OUT / a.video.stem)
    outdir.mkdir(parents=True, exist_ok=True)

    info = probe(a.video)
    print("[探针] " + json.dumps(info, ensure_ascii=False))
    dur = info["duration_s"] or 0.0

    times: list[float] = []
    if a.at:
        times = [float(x) for x in a.at.replace(" ", "").split(",") if x]
    elif a.every > 0:
        t = 0.0
        while t < dur:
            times.append(round(t, 3))
            t += a.every
    else:
        times = [0.0, round(dur / 2, 3), max(0.0, round(dur - 1 / 24, 3))]

    shots = [grab(a.video, t, outdir, fast=a.fast) for t in times]
    print(f"[抽帧] {len(shots)} 张 → {outdir}")
    for p in shots:
        print(f"  {p}")

    if a.grid:
        cols, _, rows = a.grid.partition("x")
        every = a.every if a.every > 0 else max(0.5, dur / (int(cols) * int(rows)))
        sheet = contact_sheet(a.video, outdir, every, int(cols), int(rows), a.width)
        print(f"[联络表] 每 {every:.2f}s 一格 → {sheet}")

    if a.audio:
        if not info["audio"]:
            print("[音频] 无音轨, 跳过")
        else:
            print("[音频] 调用 audio-analyze.py")
            run_audio(a.video)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

### B. `audio-analyze.py`(源码内嵌, 经 stdin 就地执行)

```python
"""音频分析: 转写/情绪/事件 + 声学特征 + 频谱图 (离线, 本地模型)。

用法:
    python - < <此文件§10.B 的源码>   # 或经 stdin 就地执行
    # 参数: <音频文件> [--asr] [--features] [--plots]

  --asr       用 SenseVoiceSmall 出转写文本 + 情感 + 事件 + 语种 (需 models\\TTS\\SenseVoiceSmall)
  --features  用 librosa/pyloudnorm 出 F0/响度/节奏/频谱特征 (可推断性别倾向与音色形容)
  --plots     用 ffmpeg 出频谱图与波形图 PNG (供看图)
"""

import argparse
import json
import pathlib
import subprocess
import sys
import tempfile

ROOT = pathlib.Path(__file__).resolve().parent.parent
SENSEVOICE = ROOT / "models" / "TTS" / "SenseVoiceSmall"


def probe(path: pathlib.Path) -> dict:
    """ffprobe 探容器/流信息。"""
    out = subprocess.run(
        ["ffprobe", "-v", "error", "-print_format", "json", "-show_format", "-show_streams", str(path)],
        capture_output=True, text=True, encoding="utf-8",
    ).stdout
    info = json.loads(out or "{}")
    fmt = info.get("format", {})
    rows = []
    for st in info.get("streams", []):
        rows.append({k: st.get(k) for k in ("codec_type", "codec_name", "sample_rate", "channels", "duration")})
    return {"format": fmt.get("format_name"), "duration": fmt.get("duration"),
            "bit_rate": fmt.get("bit_rate"), "streams": rows}


def to_wav16k(src: pathlib.Path, dst: pathlib.Path) -> pathlib.Path:
    """转 16kHz 单声道 wav (SenseVoice 输入要求)。"""
    subprocess.run(
        ["ffmpeg", "-y", "-v", "error", "-i", str(src), "-ac", "1", "-ar", "16000", str(dst)],
        check=True,
    )
    return dst


def run_asr(wav: pathlib.Path) -> None:
    """SenseVoiceSmall: 转写 + 情感 + 事件 + 语种。"""
    from funasr import AutoModel
    from funasr.utils.postprocess_utils import rich_transcription_postprocess

    model = AutoModel(model=str(SENSEVOICE), disable_update=True, device="cuda", hub="ms")
    res = model.generate(
        input=str(wav), cache={}, language="auto", use_itn=True,
        batch_size_s=60, merge_vad=True, merge_length_s=15,
    )
    for item in res:
        raw = item.get("text", "")
        print(f"  [原始标签] {raw}")
        print(f"  [可读文本] {rich_transcription_postprocess(raw)}")
        if item.get("timestamp"):
            print(f"  [时间戳]   {item['timestamp']}")


def run_features(wav: pathlib.Path) -> None:
    """librosa/pyloudnorm: F0/响度/节奏/频谱。"""
    import librosa
    import numpy as np
    import pyloudnorm as pyln
    import soundfile as sf

    y, sr = sf.read(str(wav), dtype="float32")
    if y.ndim > 1:
        y = y.mean(axis=1)
    dur = len(y) / sr
    print(f"  时长 {dur:.3f}s / 采样率 {sr}")

    meter = pyln.Meter(sr)
    print(f"  整体响度 {meter.integrated_loudness(y):.2f} LUFS")

    rms = librosa.feature.rms(y=y, frame_length=1024, hop_length=256)[0]
    times = librosa.frames_to_time(range(len(rms)), sr=sr, hop_length=256)
    loud = rms > rms.max() * 0.05
    print(f"  有声占比 {loud.mean() * 100:.1f}%  峰值 RMS {rms.max():.4f}")
    # 静音段 (连续低于阈值 >0.3s)
    runs, start = [], None
    for t, flag in zip(times, loud):
        if not flag and start is None:
            start = t
        elif flag and start is not None:
            if t - start > 0.3:
                runs.append((round(start, 2), round(t, 2)))
            start = None
    if start is not None and dur - start > 0.3:
        runs.append((round(start, 2), round(dur, 2)))
    print(f"  静音段(>0.3s) {runs if runs else '无'}")

    tempo = librosa.beat.beat_track(y=y, sr=sr)[0]
    spec_c = librosa.feature.spectral_centroid(y=y, sr=sr)[0]
    flat = librosa.feature.spectral_flatness(y=y)[0]
    zcr = librosa.feature.zero_crossing_rate(y)[0]
    mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13)
    print(f"  节奏估计 {float(np.atleast_1d(tempo)[0]):.1f} BPM")
    print(f"  频谱质心 {spec_c.mean():.0f} Hz (亮/暗)   谱平坦度 {flat.mean():.4f} (噪声性)   ZCR {zcr.mean():.4f}")
    print(f"  MFCC[1..3] 均值 {np.round(mfcc[1:4].mean(axis=1), 2).tolist()}")

    # F0: pyin 仅在有声段, 用于性别倾向与音域
    f0, vflag, vprob = librosa.pyin(y, fmin=60, fmax=500, sr=sr, frame_length=2048)
    voiced = f0[~np.isnan(f0)]
    if voiced.size:
        med = float(np.median(voiced))
        gender = "男声倾向" if med < 155 else ("女声倾向" if med > 200 else "中性/不确定")
        print(f"  F0 中位 {med:.1f} Hz  [{voiced.min():.0f}~{voiced.max():.0f}] "
              f"有声帧 {voiced.size}/{f0.size} ({voiced.size / f0.size * 100:.0f}%)  → {gender}")
        print(f"  F0 标准差 {voiced.std():.1f} Hz (语调起伏)")
    else:
        print("  F0: 未检出稳定浊音 (纯音乐/噪声/气声)")


def run_plots(src: pathlib.Path, outdir: pathlib.Path) -> list[pathlib.Path]:
    """ffmpeg 出频谱图/波形图。"""
    outdir.mkdir(parents=True, exist_ok=True)
    spec = outdir / (src.stem + "-spectrum.png")
    wave = outdir / (src.stem + "-wave.png")
    subprocess.run(["ffmpeg", "-y", "-v", "error", "-i", str(src), "-lavfi",
                    "showspectrumpic=s=1024x512:legend=disabled", str(spec)], check=True)
    subprocess.run(["ffmpeg", "-y", "-v", "error", "-i", str(src), "-lavfi",
                    "showwavespic=s=1024x256:colors=white", str(wave)], check=True)
    return [spec, wave]


def main() -> int:
    sys.stdout.reconfigure(encoding="utf-8")
    ap = argparse.ArgumentParser()
    ap.add_argument("audio", type=pathlib.Path)
    ap.add_argument("--asr", action="store_true")
    ap.add_argument("--features", action="store_true")
    ap.add_argument("--plots", action="store_true")
    a = ap.parse_args()
    if not (a.asr or a.features or a.plots):
        a.asr = a.features = a.plots = True

    print(f"═══ {a.audio.name} ═══")
    print("[容器/流] " + json.dumps(probe(a.audio), ensure_ascii=False))
    with tempfile.TemporaryDirectory() as td:
        wav = to_wav16k(a.audio, pathlib.Path(td) / "mono16k.wav")
        if a.asr:
            print("[ASR/情绪/事件] SenseVoiceSmall")
            run_asr(wav)
        if a.features:
            print("[声学特征] librosa / pyloudnorm")
            run_features(wav)
    if a.plots:
        print("[图] " + "  ".join(str(p) for p in run_plots(a.audio, pathlib.Path(tempfile.gettempdir()) / "audio-analyze")))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
