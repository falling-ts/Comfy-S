# 局部编辑与遮罩专题(含「抹平手部血管」实战复盘)

## 1. 遮罩是官方支持的通道,但不是"像素级保险"

官方 README 明确 2.1 可 *"specify local edits via circles, painted annotations, or **separate masks**"*
⇒ **遮罩合法、没问题**。问题在于**它不保证严格贴边界**。

官方仓库 [issue #137](https://github.com/QwenLM/Qwen-Image/issues/137)
标题 *"Qwen-image-edit inpaint cannot be conditioned to fit inside a masked area"*,
**至今 open、0 回复**:

> 生成内容经常不贴合遮罩;模型想画的对象比遮罩大 → 在遮罩边缘被裁切,
> 破坏"外部必须完全不变"的精确编辑。

**已实测无效的做法**:在提示词里写
`Inpaint only the masked region. All new/changed pixels must be fully contained within the mask boundary. Do not alter any pixel outside the mask.`
—— **靠提示词要求模型尊重遮罩边界不可靠**。

### 结论:严苛的"只改这里"要走 crop-and-stitch

```
原图 → (遮罩) → ComfyUI-Inpaint-CropAndStitch 裁出遮罩区域
     → 只对该小图做 Qwen 2.1 编辑(此时"全图"就是手部,无需它尊重边界)
     → 贴回原图
```

本机**已装** `custom_nodes\ComfyUI-Inpaint-CropAndStitch`。
这条路同时缓解两个问题:①边界不保证 ②局部在大图里占比太小导致编辑强度被稀释。

## 2. 「抹平手部血管凸起」为什么特别难 —— 四重叠加

### 2.1 编辑方向与模型先验相反

"血管暴起"在写实渲染里是**细节**;而生成模型**默认倾向增加细节**。
要求"抹平血管、弱化肌腱轮廓、恢复皮下脂肪饱满" = **要求模型做减法并保持解剖可信**。
这正是官方 L33 定义的 **Under-editing 高发区**:模型倾向保守,给你一张"几乎没变"的图。

### 2.2 保留条款压过编辑强度(L35)

原写法把大量篇幅用于描述**要保留的**(构图/背景/光影/身份/姿态),
按 L35「保留锁的是内容,不是编辑强度」—— 但**过量**的保留描述在实践上会把改动压平。
判据:输出与输入**难以区分** = 正是官方说的 "an output a viewer could mistake for the unedited input"。

### 2.3 保留描述写成"逐项枚举" = 反而诱导重画(L41)

```
✗ 保持图1原有的英俊面部、清爽黑发、身材比例、正面站姿与服装完全一致，
  五官、发型、身高与衣物不得改变
✓ 保持<image1>的人物身份、画面内容与构图完全不变
```

前者是 L41 点名的 `walking the frame`;原文说这种描述**会被模型读成生成指令**,
于是算力被花在**重新生成脸/头发/衣服**上,真正想做的"手部细腻化"被稀释。

### 2.4 正负词拉锯

```
正词：保留清晰可辨的真实毛孔、细微绒毛与次表面散射通透感
负词：血管暴起, 青筋凸起, …, 指甲畸形（40 条）
```

正词要保细节、负词整体在压细节 ⇒ **净效果两者都弱**。
且 40 条负词远超官方示例(官方示例**几乎不用负词**)。

## 3. 改法(按官方规范)

### 3.1 结构:改动写强,保留压成一句

```
保持<image1>的构图、机位、景别、光影与画面内容完全不变，
只将遮罩选中的双手处理成皮肤细腻平滑、
皮下脂肪饱满、血管青筋与肌腱轮廓完全平复的健康手部，
手部光影方向与色温与<image1>完全一致。
```

要点:
- **一句**笼统保留(`保持…完全不变`),不逐项枚举
- 改动推到**强而明确**:`完全平复` > `弱化到不易察觉`
- 删掉弱化词 `轻微`/`略微`/`稍稍`/`尽量`
- 删掉 `整体是…出门时的模样` 这类**与底图矛盾**的段(底图是雨夜书房坐姿,不是出门)

### 3.2 改写前后对照

| 项 | 原写法 | 改后 |
|---|---|---|
| 图号 | `图1` | `<image1>` |
| 保留 | 逐项枚举五官/发型/身高/衣物 | 一句 `保持…完全不变` |
| 改动强度 | `弱化`、`不易察觉` | `完全平复`、`细腻平滑` |
| 负词 | 40 条 | ≤10 条,只留本次要压的 |
| 段数 | 5 段(`<br>`) | 表内保留 `<br>`,**送模型前合成单段** |
| 与底图矛盾处 | 有(`出门时的模样`) | 删除 |

### 3.3 负词怎么砍

只留**本次真正要压的**:

```
血管暴起, 青筋凸起, 手部浮肿, 手指粗短
```

删掉:质量标签类、与手无关的全身项、与正词拉锯的"保细节"项。

⚠️ 注意:官方规范**极少用负词**,且要求正面表述。
本库仍保留负词列(表结构要求),但应视为**辅助**,不要靠它承担主要控制。

## 4. 本库踩坑实录(2026-09-24)

### 4.1 `原图`/`图1` 填错 → 遮罩与底图不同源

曾把 `原图`/`图1` 填成 `@{0011_万物建模/00001_陈落}`(白底建模立绘),
但遮罩是涂在**雨夜书房关键帧**上的。

⚠️ **铁律:遮罩必须涂在该条的底图上。底图换了而遮罩没换 = 遮罩位置全错,编辑必然失败。**

已改为对应关键帧:
- `00002_陈落手部修改全景` → `@{0044_参考视频/00001_书房开场四镜关键帧1}`
- `00003_陈落手部修改特写` → `@{0044_参考视频/00001_书房开场四镜关键帧2}`

**配对校验口径**(可靠):灰度平均绝对差 —— 正确配对 `0.0`,错配 `84.1`。
⚠️ 不要用"alpha 判涂白"(遮罩 PNG 的 alpha 处处含帧内容,会得 98.9% 的假阳性)。

### 4.2 插件侧静默 bug(preview-image 缓存作用域)

`preview-image` 加工作流作用域后写入键变成 `"<工作流根 id>::<节点 id>"`,
但 `mask-rename` 仍用裸 `node_id` 取 ⇒ 永远 `None` ⇒ `base` 静默退化成 `mask-{ts}`。

教训:**改缓存键格式时必须全局搜所有读者**,`mask-rename` 是该 scoped 缓存的唯一外部读者。

### 4.3 `<br>` 分段 vs 官方单段的正确处置

两者**都要满足**:

- md 表格单元格内**真实换行会断开表格** ⇒ 表里必须 `<br>`(`stories` 规范,正确)
- 官方要求送进模型的 `rewritten_prompt` **单段无换行**

⇒ **表内用 `<br>`,`<br>` 在送出前合成**(替换为 `。` 或空格)。
这需要改工作流或 mdtable 节点;在改之前,至少要知道**当前是带着 `<br>` 直接送模型的**,
这本身就是与官方规范的一处偏差。

### 4.4 实测:格式校验器全部通过

本库三行跑官方校验器**全部 `pass=True`** ⇒ 失败**不是格式问题**,是**语义**问题。
不要把 `validate_prompt.py` 当有效性判据。

## 5. 局部编辑自检清单

- [ ] 遮罩涂在**该条的底图**上(底图与遮罩同源)
- [ ] 用灰度平均绝对差验证配对(不是 alpha)
- [ ] 保留是**一句**声明,没有逐项枚举外观
- [ ] 保留篇幅**没有超过**改动篇幅
- [ ] 改动推到**强而明确**,没有 `轻微`/`尽量`/`略微`/`不易察觉`
- [ ] 没有与底图矛盾的描述(检查"整体是…"段是否还在沿用别的条目语境)
- [ ] 负词 ≤10 条,且与正词不拉锯
- [ ] 提示词里**没有**要求模型"不要改动遮罩外像素"(做不到,见 §1)
- [ ] 若要求"只改很小一块",考虑 **crop-and-stitch** 而非全图+遮罩
