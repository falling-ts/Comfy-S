# H3 场景生成：多轮实测结论

本机实测（RTX 4060 8GB / ComfyUI 0.35.0 / H3 4 步 turbo LoRA），5 次真实渲染 + 定量分析。
文中每个数字都可用本技能的 `output-verification.md` 方法复现。

## 一、性能对比总表

| 方案 | 参考输入 | 运动标准差 | 视角覆盖 | 备注 |
|---|---|---|---|---|
| **首帧场景 + 优化提示词** | 1 张锚点图 | **14.6** | ✅ 完整 360° | **最优** |
| 参考场景 Ref2VA | 4 张**同源**视角图 | 15.1 | ✅ 完整 360° | 次优 |
| 参考场景 Ref2VA | 4 张**逐格独立**生成的图 | 24.1 | ✅ | 家具漂移、凭空增减物件 |
| 首帧场景（原提示词） | 1 张锚点图 | 21.8 | ⚠️ 含推镜 | 提示词含"向前前冲" |
| OrbitSheets（cut views, 4 视角） | 1 张锚点图 | — | ⚠️ 缺 1 面 | 场景被改写 |
| OrbitSheets（continuous move） | 1 张锚点图 | — | ❌ 全在一侧 | 5 秒转距不够 |

**指标口径**：
```bash
ffmpeg -hide_banner -i v.mp4 -vf "fps=2,scale=160:90,tblend=all_mode=difference,blackframe=amount=0:threshold=10" -f null - 2>&1 | grep pblack
```
取 pblack 序列的**标准差，越小越匀速**（pblack 越大=运动越小；尖峰=停滞，谷值=猛冲）。

## 二、最反直觉的结论：单图锚点优于多图参考

```
单图 + 好提示词   →  14.6   ← 最优
四图（同源）      →  15.1
四图（矛盾）      →  24.1
```

**条件越简单，模型越不容易被拉散。** 多图的价值在于提供模型自己推不出来的侧面信息，代价是引入更多互相牵制的条件。**只在"确实需要模型知道背面/侧面"时才上多图。**

一致性是硬前提、优先于视角精确度：给互相矛盾的图，模型没有裁决能力，只能在矛盾间摇摆（实测表现为家具漂移、凭空多出显示器与书堆）。

## 三、提示词的五条硬经验

**1. 正面陈述，不要否定式惩罚**

H3 不可靠遵守否定式指令——把"不要倾斜/不要翻滚"这类词写进去，等于把那些运动类型的名字递给模型。

- ✗ "镜头保持水平，不会倾斜、不会翻滚、不会加速"
- ✓ "地平线保持水平，墙面与柜体的垂直线保持垂直，地板沿画面底边、天花板沿画面顶边"

实测：仅此一改，标准差 **21.8 → 14.6**。

**2. 明说"固定机位 + 原地水平转动"**

只说"360 度环绕/环视"会得到**推镜平移**（画面内容横向滑过、主体从中央滑向一侧），不是原地转身。

- ✓ "机位固定于房间中央约一米五高处，全程只做原地水平转动：不向前后移动、不向左右平移、不升降、不改变高度"
- 术语坑：`orbit` 在影视术语里指"机位绕着被摄体转圈"；"站在中央转身"应表达为**固定机位 + 原地转动**

**3. 一个镜头只做一件事**

"先前飞推近再旋转 360°"在 10 秒内做不完 → 末段崩坏。需要前飞就单独一条镜头。

**4. 绝不描述参考图自身的版式与标注**

写了"2×2 拼合的图片""每格左上角印有白色粗体中文方位标注"之后，模型**把分格线与方位文字直接画进了画面**。只说"参考图提供哪几个方向的视图"，并补正面保护句：

> 参考图只是布局依据，它本身不会出现在画面中，其中的任何分格、边框、拼贴痕迹或注记文字也都不会出现在画面里。

**5. 物件名词不能有歧义 —— `notebook` 会被画成第二台笔记本电脑**

英文 `notebook` 兼指「笔记本电脑」与「记事本」。桌上同时写 `a laptop` 与 `a closed black notebook` 时，
模型会把 `notebook` 渲染成**第二台（闭合的）笔记本**（实测 `0044_参考视频` 第三段：桌面出现两台笔记本状设备，
用户直接指出"出现两个笔记本"）。把两个物件**并列在一句里**也会被拆开：

- ✗ `a closed black notebook, a pen and a row of upright books`
  → ✓ `a closed black paper journal, a pen and a row of upright books`
- ✗ `the laptop and keyboard stay untouched in front of him`
  → ✓ `his one single lit laptop stays untouched in front of him`
  （键盘是笔记本的一部分，不要另列为桌面物件）
- 顺手补一句正面限定：`that laptop is the only computer anywhere in the room`

排查手法：把桌上每个小物件的说法换成**唯一无歧义**的名字，改完抽帧数一遍物件。这类错误**不报错**，
只能在成片里看出来。

## 四、速率上限

| 环绕角度 | 最短时长 | 帧数 |
|---|---|---|
| quarter 90° | 2.3 s | 124 |
| half 180° | 4.5 s | 124 |
| **full 360°** | **9 s** | **220+** |

- H3 官方示例：360° / **15 秒**（= 24°/s），措辞 *"a slow constant rate, completing exactly one full rotation across fifteen seconds"*
- 实测安全上限 ≈ **40°/s**，超过即翻滚（画面倾斜、卷向天花板、地板格铺满画面）
- 10 秒 360° = 36°/s（可行）；12 秒 = 30°/s（可行）；5 秒 = 72°/s（必翻）

## 五、参考图一致性的量化证据

逐格独立生成的四图（如 Qwen-Image-Edit 多视角）会结构性漂移，实测同一场景：

| 物件 | 图 A | 图 B |
|---|---|---|
| 斗柜抽屉数 | 3 | **4** |
| 衣帽架数量 | 2 | **1** |
| 琴叶榕数量 | 2 | **1** |
| 音箱摆放 | 并排 | **叠放** |

**唯一可靠来源**：同一段视频的选帧（天然时间一致）。禁止把逐格独立生成的多视图直接当多视图参考。

## 六、场景参考板（OrbitSheets 插件）的实测边界

> ⚠️ **2026-10-21：该插件与工作流 `0033_OrbitSheets场景` 均已从本机移除。** 本节保留为历史实测结论 ——
> 结论本身就是「拼板不如拆帧」，正好解释了为何不必再装：需要多视角参考时直接用同一段视频拆帧即可。

**它编不出锚点图里没见过的面。** 其文档自己写明：*"told to cut to 'the rear', it either re-frames the facade it already has or invents somewhere else"*。实测三次均印证：缺 1 个方向、凭空加 LED 灯带、少书架、多出柜门。

**当时的参数配方**（仅供复现历史实验参考；插件已移除，现已无法运行）：
```
coverage               = cut views     # continuous move 在 5 秒内覆盖太窄
wide_establishing_shot = False         # 开着会浪费槽位（实测 2 格重复）
detail_shot            = False
shots = count          = 4             # 两者相等即跳过视觉模型
label_prefix           = ""            # 否则烧字随参考进入下游
```

**正确用途**：手上没有现成多视角图时快速凑一块板。**已有视频可拆帧时，直接拆帧更好。**

**必须读 `info` 输出**：出现 `only N distinct views in these X frames` 说明视角重复（发生在选帧之前，任何选帧器都救不了）。

## 七、改参数的四个坑（都踩过）

1. **`widgets_values` 的槽位顺序 = `widgets_values_named` 的键顺序**，**不是** `/object_info` 的输入顺序——后者含 `images`/`clip` 等非控件输入，照它猜索引会整体错位（曾把 `mode` 从 `"vision_llm"` 改成 `4`、把 `shot_split` 改成 `4`）。
2. **在 GUI 里保存工作流会覆写磁盘上的参数修改**（前端用内存状态写回）。用 API 跑就不要同时开 GUI 保存，否则改了等于没改。
3. **`Set-Content -Encoding UTF8` 在 Windows PowerShell 会写 BOM**，ComfyUI 无法解析工作流。须用 `[System.IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding $false))`。
4. **工作流 mdtable 的 `selected.id` 必须与 md 里的行 ID 一致**，否则 `--refresh-md` 报"md 中找不到行"。用 `scripts/set-md-selected-id.py` 对齐。

## 八、抽帧的两个陷阱

- **`fps=2/3` 在 10 秒视频上会取到 10.5 秒的帧**，超出部分被 ffmpeg **补黑** —— 看起来像"视频末尾黑屏"，其实是抽帧伪影。先算 `帧数 = 时长 × fps`，或用 `signalstats` 的 `YAVG` 直接测末帧亮度。
- **判"是否黑屏"用 `blackframe=amount=95:threshold=20`**，不要靠肉眼看拼图。
