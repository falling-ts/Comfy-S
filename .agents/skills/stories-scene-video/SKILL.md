# 故事库场景视频资源规范

> 尺寸与语言规范见技能 `stories-resource-tables`（H3 canvas 桶与「提示词正文一律中文」）。场景方位词（面/侧/边）与画面边缘词（缘）的定义见技能 `stories-resource-tables` 的「画面术语定义」。镜头运动术语见技能 `stories-shot-language`。本技能与 `stories-video-prompts` 同属 H3 视频，只是对象是场景而非人物/主体。

### 场景类公共要求（文生场景 / 首帧场景 / 参考场景 通用）

**旋转与视角硬性要求**：场景视频以**平视视角**（镜头高度与视线齐平）完成 **360 度顺时针完整旋转**，画面以场景中央为轴从起始正面开始顺时针旋转一周，旋转过程连贯匀速一气呵成，**角速度全程恒定、一次连续转完**；镜头转到 **90°、180°、270°** 三个方位时把该方向看到的场景内容交代清楚，随后继续匀速转向，最终回旋至起始正面方向，起点终点画面完整衔接成**闭合环绕**。各方位视角之外另补一份 **全图** 俯瞰整体描述（按「全图方位」要求，用俯视平面图方位词逐区域点名整体布局），使场景还能从平面视角一并还原。

**为什么不停顿（2026-09-13 本机实测）**：在 90°/180°/270° 各停顿 0.5 秒会让模型在停顿点卸力、停顿结束后再猛冲追赶，表现为物件在画面里凭空出现与位移。同一场景、同一随机种子的 A/B 实测：运动逐帧变化量（pblack）标准差 **15.9 → 8.5**（去停顿后匀速性提升 46.5%），最小值从 **15**（猛冲段）回到 **30**；拼图核对显示带停顿版会在旋转中段长出首帧里根本不存在的落地灯、成堆纸箱与墙面搁架。**提示词里用正面陈述表达不停顿**（如「角速度自始至终保持不变」「整圈一次连续转完」），不要写「不停顿」「不加速」这类否定式——H3 对否定式指令不可靠。

**镜头旋转时，必须保持物体位置与空间关系全程一致，画面单镜连贯**，使 360° 环绕稳定还原整个场景。

**场景空间描述要求**：必须完整交代场景空间的大小（面积或尺度）与**整体布局**，并按**各方位视角逐一描写该方向看到的场景内容**——起始正面（0°）、转到 90° 时正对的正右方、转到 180° 时正对的正后方、转到 270° 时正对的正左方、回旋回归正面，五个节点逐一交代当前方向上的场景内容（物件、墙面、灯光、空间细节及其相互位置关系），用方位词（前/前右/右/右后/后/后左/左/左前）点名每件物件的空间位置，使 360° 环绕镜头能稳定、无遗漏地还原整个场景；保持角色、物体与空间关系一致。

**各方位视角画面描述要求（场景类通用）**：镜头转到的每个方位均须把该方向看到的画面内容交代清楚（该方位下的物件、墙面、灯光与空间细节），让模型据此逐方位还原画面。各方位之间的**过渡界面衔接一致**为硬性要求（顺时针 前→前右→右→右后→后→后左→左→左前，每个视角画面的右缘与下一视角画面的左缘是同一物理区域的延续）：
- **前面**右边 与 **前右**左边 重叠
- **前右**右边 与 **右面**左边 重叠
- **右面**右边 与 **右后**左边 重叠
- **右后**右边 与 **后面**左边 重叠
- **后面**右边 与 **后左**左边 重叠
- **后左**右边 与 **左面**左边 重叠
- **左面**右边 与 **左前**左边 重叠
- **左前**右边 与 **前面**左边 重叠

重叠区域内的内容（物件、灯光、空间元素）在相邻方位视角画面中互相衔接一致——同一物理区域是前后视角画面边缘处的同一延续（90° 处的正右面衔接前方正面的右缘，180° 处的正后面衔接右面的右缘，270° 处的正左面衔接后面的左缘，回旋正面衔接左前右缘与起始正面左缘）；描述与生成均按此关系交叉印证，360° 环绕每一面稳定、无遗漏地还原。

**参考视角顺序（八方位八视图）硬性要求**：给 H3 提供八方位视角参考图时，必须按**旋转顺序**提供并逐张点名方位，顺序固定为俯视视角下的**顺时针「前→前右→右→右后→后→后左→左→左前」**（与 0033 OrbitSheets 参考板视角顺序一致），其中 **90°、180°、270° 三张主格对应正右、正后、正左三个方位视角**，其余斜向视角为旋转过渡帧。参考段须逐张点明相邻视角为绕主体旋转 45° 的机位（如「图1=正前方视角；图2=顺时针转 45° 的前右视角；图3=再转 45° 的右侧视角；图4=再转 45° 的右后视角；图5=再转 45° 的后方视角；图6=再转 45° 的后左视角；图7=再转 45° 的左侧视角；图8=再转 45° 的左前视角」），并声明「目标镜头沿同一方向顺时针旋转，过渡角度取相邻两图之间的中间视角」。图序是给模型的旋转轨道暗示，必须与目标镜头旋转方向一致，方向相悖会干扰空间连贯（尤其 360° 环绕）；静止/无旋转镜头固定沿用默认顺时针顺序，故事内全局保持一致。


### 12 秒八镜 360° 旋镜定式（Shot 1–8，场景类默认写法）

**适用**：`0030_文生场景` / `0031_首帧场景` / `0032_参考场景` 三条场景类提示词的**默认写法**，一律套用；用户明确要求别的时长或镜数时才偏离。它把「场景类公共要求」里 360 旋转、角速度恒定、方位衔接一致、不停顿、不否定式等硬性要求落成一套**固定模板**（已在 `0031_首帧场景` 的 12 秒八镜行实测落地）。

> 注：存量 `0030_文生场景` 第 1 行、`0031_首帧场景` 第 1 行仍是旧的「10 秒 / 四段散文」版，**改写时统一到本定式**。

**固定参数（不与每次商定）**

| 项 | 值 |
|---|---|
| 视频秒数 | **12**（表内 `视频秒数(INT)` 填 `12`；按 H3 的 17k+5 帧网格向上吸附为 **294 帧 ≈ 12.25 秒**，提示词里的 12.00 秒闭环落点按实际时长取整） |
| 尺寸 | 按技能 `stories-resource-tables` 的 H3 canvas 规则（默认 832×480） |
| 总转角 | **360 顺时针**一周，起点 = 终点，闭环 |
| 角速度 | 恒定 **30 度/秒**（1.5 秒 / 45 度、约 1.25 度/帧 @24fps），低于 H3 的 **40 度/秒 翻滚上限** |
| 机位 | 固定在场景中央的**空中一处静止点**，视线保持水平（eye level）不俯仰；只绕自身竖轴旋转，不升降、不横移、不变焦、不后退、不穿家具 |
| 镜头数 | **8**，每镜 1.5 秒转过 45 度 |

**Shot 与八方位、秒数对照（固定）**

八方位顺序与「参考视角顺序（八方位八视图）」完全一致（前→前右→右→右后→后→后左→左→左前），所以参考图、参考板、提示词的方位口径天然对齐；三个主方位（右 90 度 / 后 180 度 / 左 270 度）恰好落在 `[Shot 3]` / `[Shot 5]` / `[Shot 7]` 的起点。

| 镜 | 写进提示词的秒数标记 | 起始方位 | 该镜转过 |
|---|---|---|---|
| `[Shot 1]` | **不写秒数**（固定 0） | 正面 0 度 | 0 度→45 度（正面→前右） |
| `[Shot 2]` | `At 00:01.500` | 前右 45 度 | 45 度→90 度 |
| `[Shot 3]` | `At 00:03.000` | 右 90 度 | 90 度→135 度 |
| `[Shot 4]` | `At 00:04.500` | 右后 135 度 | 135 度→180 度 |
| `[Shot 5]` | `At 00:06.000` | 后 180 度 | 180 度→225 度 |
| `[Shot 6]` | `At 00:07.500` | 后左 225 度 | 225 度→270 度 |
| `[Shot 7]` | `At 00:09.000` | 左 270 度 | 270 度→315 度 |
| `[Shot 8]` | `At 00:10.500` | 左前 315 度 | 315 度→360 度，**12.00 秒处回到 `[Shot 1]` 的起点构图，闭环** |

**`[Shot 1]` 的画面来源（三条场景表唯一差别）**
- **文生场景**：首帧由提示词首句承载（风格 + 正面构图），不引图
- **首帧场景**：`<Picture 1>`，且首行照抄 I2VA 英文对齐指令 `For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.`
- **参考场景**：按 Ref2VA 六段结构，`[Shot 1]` 的首帧来自 reference subject 的锚定描述

**提示词结构（三段）**
1. **前置段（场景总览）**：先写风格、空间尺度（面积/长宽）、四面墙在四角直角相接、踢脚线绕墙一周、整体明暗；再**按八方位逐一清单每件物件与大概方位**（前/前右/右/右后/后/后左/左/左前），拍不到的墙面每块留 1 件简单家具作锚点；必要时写「只有四面实心墙、无第五面墙无门洞」之类正面约束。该段不写镜头运动。
2. **机位段**：写明机位静止、eye level、地平线水平、纯顺时针匀速、**角速度一词**（每秒 30 度，整圈在 12 秒内完成）、全程不升降横移变焦后退；并声明**整条是同一个连续镜头，`[Shot 1]`–`[Shot 8]` 只是这段连续旋转在时间轴上的八个等分时段标注，不剪切**；补一句平移规则「左侧内容朝画幅左缘移出，下一面墙从画幅右缘连续进入、滑向中央，每件物件只经左缘或右缘进出视野、不凭空出现消失；前一面墙右缘与后一面墙左缘是同一墙角/墙地交线的连续延续」。
3. **八镜段**：`[Shot 1]`（无秒数）→ `[Shot 2] At 00:01.500` → … → `[Shot 8] At 00:10.500`，每段写「当前正对哪一方位、画面左/中/右各是什么、本段向左缘移出什么、从右缘移入什么、段末正对下一方位」，末段收束到 12.00 秒回到首帧构图、首尾衔接成闭合环绕。

**每段固定句式（画面左缘移出 / 右缘移入，正是用户给定的衔接口径）**
> 本段画面**左侧的内容正渐渐移出画幅左缘**，同时**下一面墙（下一镜头要看到的内容）从画幅右缘连续进入、一点点滑向画幅中央**；前一面墙的右缘与后一面墙的左缘是同一处墙角与同一道墙地交线的连续延续，每件物件只经画幅左缘或右缘进出视野、不凭空出现或消失。

**不可破的硬要求（与「场景类公共要求」一致）**
- 角速度恒定、一次连续转完，不用否定式停顿/吸附（见「场景参考图与 H3 运镜实测经验」四/五）；用正面陈述表达不停顿（如「角速度自始至终保持不变」「整圈一次连续转完」）
- 每面墙/每块空白墙有实体锚点，件数克制（见「场景参考图与 H3 运镜实测经验」八/九），用正面清点句压数量
- 闭环：12.00 秒处回到 `[Shot 1]` 起始构图与同一组锚点
- 12 秒满足 `0034_世界模型` 的「≥9 秒」合格线，可直接被其复用

### 文生场景

即利用文生视频（提示词按上文「12 秒八镜 360° 旋镜定式」写）获取具体描述的场景360度视频，包含ID，场景提示词(TEXT)，宽度(INT)，高度(INT)，视频秒数(INT)

#### 写入时机

**需要我明确说明写入哪些内容时，才可以写入**；分析正文内容时，**不允许自动写入**。

#### 文生场景 提示词提取规范

场景提示词按 **T2VA** 规范书写，直接以三个核心字段开头，无图像对齐指令：

1. **integrated_multimodal_description**：沿时间线描述场景的视觉风格、初始构图、空间布局与镜头运动，交代九方位（前/前右/右/右后/后/后左/左/左前/全图）及上下的空间方位、环境、光线与氛围
2. **overall_soundscape**：概括整个视频中的环境音与物理动作声
3. **non_diegetic_music**：描述角色听不到、仅观众能听到的背景音乐

场景类公共要求（见上节）在本类型中落实于 integrated_multimodal_description。

### 首帧场景

即利用首帧生视频（提示词按上文「12 秒八镜 360° 旋镜定式」写）获取具体秒数的场景360度视频，包含ID，<Picture 1>(IMAGE)，场景提示词(TEXT)，宽度(INT)，高度(INT)，视频秒数(INT)

#### 写入时机

当**场景首帧**写入后，**紧接着写入首帧场景**，图就是首帧；根据首帧获取整个场景在 **起始正面（0°）、转到 90° 时正对的正右方、转到 180° 时正对的正后方、转到 270° 时正对的正左方、回旋回归正面** 各方位视角以及 **全图** 方位俯瞰画面的内容。各方位视角画面内容必须满足「场景类公共要求 → 各方位视角画面描述要求」的**过渡界面衔接一致**（前面右缘↔前右左缘、前右右缘↔右面左缘、右面右缘↔右后左缘、右后右缘↔后面左缘、后面右缘↔后左左缘、后左右缘↔左面左缘、左面右缘↔左前左缘、左前右缘↔前面左缘，界面衔接区域内容在相邻方位视角画面中保持一致）。

#### 首帧场景 提示词提取规范

场景提示词按 **I2VA** 规范书写，首帧为视频在 0.00 秒的实际第一帧：

1. 第一行对齐指令：`对于目标视频，在目标视频的 0.00 秒处，<Picture 1>（来自 [Shot 1]）被完整引用。`
2. 空一行后写三个核心字段：integrated_multimodal_description、overall_soundscape、non_diegetic_music

integrated_multimodal_description 先在图像中确立场景风格、主体、构图与空间锚点，再从首帧出发以平视机位沿顺时针展开完整 360 度视角旋转，角速度全程恒定、一次连续转完，保持角色、物体与空间关系一致；转到 90°、180°、270° 三个方位时，各方位视角及过渡界面按**过渡界面衔接一致**交叉印证（见「场景类公共要求」）。

场景类公共要求（见上节）在本类型中落实于 integrated_multimodal_description。

**图片标签使用**：首帧图用 `<Picture 1>` 引用（对齐指令中即为 `<Picture 1>`）。此模式**不使用 `<Subject N>`**，画面内容一致性通过 integrated_multimodal_description 中「保留 <Picture 1> 的场景 X、Y、Z」之类的文字描述维持。

### 世界模型（0034：360° 环绕视频 → 3DGS PLY）

即把**一条** 360° 环绕视频重建成一个最高质量 3DGS PLY 的**入口表**：包含 ID，场景描述(TEXT)，360环绕视频(VIDEO)，**每行 = 一个可重建的封闭场景**（房间 / 院子 / 车厢这类边界清楚的紧凑空间）。下游工作流 `0034_世界模型`：md 表 → `WorldSurroundPanorama`（视频 → 等距圆柱长图）→ `WorldPanoramaViews`（长图 → 带精确位姿的视角批）→ `WorldRefinePLY`（504 前馈 + 3DGS 全参数精修）→ PLY 视口；产物 `media\<项目>\0034_世界模型\0034_世界模型_世界3DGS.ply`。

#### 写入时机

**需要我明确说明写入哪些内容时，才可以写入**；分析正文时**不允许自动写入**。写入前先确认 `0031_首帧场景.md` 里对应的旋镜视频**已经生成并抽帧核对过**——本表只做复用，不催生新视频。

#### 世界模型 写入规范

- **视频来源**：`360环绕视频` 列一律引用 `0031_首帧场景` 的那条旋镜视频行：`@{0031_首帧场景/<该行ID>}`（例 `@{0031_首帧场景/00001_书房旋镜}`）。同一条视频既当 360° 环绕镜头、又是重建输入，所以 **0031 那段提示词的方位锚点、件数克制、单镜连贯要求直接决定重建质量**
- **TEXT 是整间房的闭合描述**：四面墙（前/右/后/左）各自的门窗、墙面、墙角、踢脚线，加地面、天花，以及每件家具贴在哪个墙面的哪一段、朝向如何，全部写全。**不写单面视角**；这里也没有 H3 的三个字段（它不驱动生成，只描述被重建的对象）
- **TEXT 末尾写明拍摄口径**：以场景中央为圆心、视线保持水平不俯仰、顺时针转满一整圈、单次连续拍摄（无剪辑、无多段拼接、无多张图）。展开算法正是靠「首末帧几何重合」判定整整一圈并把总转角吸附成 360°
- **视频合格线**（引用前抽帧核对）：单次连续拍摄、视线水平、顺时针、完整一整圈、**时长 ≥9 秒**。出现翻滚、中段猛冲或长时间静止、明显回不到起点的，先回 0031 改提示词重生成。H3 侧完整 360° 要 **220+ 帧**、转速上限约 **40°/s**（≈1.7°/帧 @24fps），超过必翻滚
- **转速不在展开侧卡脖子**：展开算法实测**匀速 0.75°~45°/帧**可用、60°/帧 起报错，且对**不均匀转速**（静止段 + 甩镜段 + 中段突发 + 两段式）能自适应补密——真机上真正卡住的是 H3 的 40°/s
- **纹理要求**：每面墙都留实体锚点（门、柜、书架、绿植、挂钟等），纯色墙 + 空房间特征匹配不稳、展开不准
- **一行一个场景**：换房间、改布局 = 换一行

#### 参考场景 提示词提取规范

场景提示词按 **Ref2VA 全参考模式** 规范书写，包含六部分，顺序固定：

1. **subject_definitions**：定义被参考内容及其参考标签，使用 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` 四类标签。`<Subject N>` 用于可复用内容（场景、地形、环境、建筑、道具、风格），`<Picture N>` 用于充当帧锚点的图片，`<Video N>` 用于剪辑、续写或参考节奏的源视频，`<Audio N>` 用于被复制或引用的音频
2. **summary**：以 `[任务类型]` 前缀开头（如 `[reference generation]`、`[video continuation]`、`[audio reuse]`），概括目标场景与主要参考关系
3. **retention_analysis**：逐项描述被参考内容如何保留、转移或复用。可见内容用 `fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`，音频用 `fully_copy` / `partially_copy` / `reference` / `weak_reference`
4. **detailed_description**：按播放顺序逐镜头描述场景画面、运镜、空间布局与声音，在首帧、尾帧、分镜等作用位置插入参考标签
5. **overall_soundscape**：概括环境氛围声与物理音效
6. **non_diegetic_music**：描述仅观众可闻的背景音乐

参考标签一旦赋予某段内容，在全部六部分中始终表示同一含义，不得换义或遗漏。**detailed_description 中必须持续使用参考标签，不得换成纯文字指代**：首次出现时写「标签 + 完整特征描述」落地到具体画面，后续镜头继续使用同一标签（无需重复定义），可配简略文字。标签是模型将画面内容与具体参考素材绑定的锚点，纯文字无法确定对应关系，尤其在多参考（≤9 图 + 3 视频 + 3 音频）时易串。

**Subject 三层绑定机制**：

1. **subject_definitions 登记**：文字描述内容并编号，建立「`<Subject N>` = 某内容」的映射关系
2. **detailed_description 首次出现落地**：写「标签 + 完整特征描述」，把编号真正绑定到具体画面特征。这一步是模型建立编号与画面对应关系的关键，只写编号不写特征会导致绑定变弱
3. **后续镜头纯引用**：直接使用同一标签引用即可，无需重复描述，可配简略文字

**图片编号按输入顺序、内容定位靠文字**：`<Picture N>` 按参考图输入顺序编号（images → videos → audio 各类型独立编号），与画面内位置无关；一张图内多个元素归属哪个 Subject 必须用文字点名（必要时用方位词辅助），模型不会自动按画面左右分配。**多视图参考（八方位视角图）必须按旋转顺序输入并在参考段逐张点名方位，顺序遵循「场景类公共要求 → 参考视角顺序」硬性规定**（默认俯视顺时针「前→前右→右→右后→后→后左→左→左前」，方向随目标镜头旋转方向对齐）。

### 场景参考图与 H3 运镜实测经验（2026-09-11 本机实测）

以下结论均来自本机实测（RTX 4060 8GB / ComfyUI 0.35.0 / 4 步 turbo LoRA），写入规范以免重复踩坑。

**一、参考图的跨图一致性是硬前提，优先级高于视角精确度**

- 逐格独立生成的参考图（如 Qwen-Image-Edit 多视角）**必然出现结构性漂移**：实测同一套四图中，同一只斗柜一处 3 抽屉、一处 4 抽屉；衣帽架一处 2 个、一处 1 个；琴叶榕 2 盆对 1 盆；音箱一处并排、一处叠放
- Ref2VA 把所有参考图一并作为条件，**互相矛盾的图 = 互相冲突的条件**；模型没有裁决能力，只能在矛盾间摇摆，表现为家具漂移、凭空多出或减少物件
- **唯一可靠来源**：参考图必须取自**同一段视频的选帧**（如同一镜头运镜视频），天然满足时间一致性
- **禁止**把逐格独立生成的多视角图直接当作多视图参考

**二、绝不在提示词里描述参考图自身的版式与标注**

- 实测：提示词写入「一张 2×2 拼合的图片」「每格左上角印有一行白色粗体带黑描边的中文方位标注」之后，模型**把分格线与方位文字直接画进了画面**（reference leakage），须两轮修正才清除
- **正确写法**：只说明参考图「提供了哪几个方向的视图、用于确定什么」；并补一句正面保护句——「参考图只是布局依据，它本身不会出现在画面中，其中的任何分格、边框、拼贴痕迹或注记文字也都不会出现在画面里」
- 参考图若已烧录文字标注，除提示词排除外，更根本的是在生成端就不烧字（OrbitSheets 的 `label_prefix` 应清空）

**三、离散参考视角会导致「吸附」，且提示词改不动**

- 实测（4 个正交参考视角、12 秒 360°）：镜头位于参考方位时的帧间运动量 pblack 均值 **71.6**，偏离 30° 处仅 **44.0** —— 靠近参考视角时**慢 63%**，即模型在参考姿态上停住、在中间猛冲
- 机理：模型把离散参考姿态当成「要对齐的目标」。**锚点越稀吸附越强**；把锚点加密只是把「大锯齿」变成「密锯齿」，并未消除
- 该现象**无法用提示词修正**（冲突在条件层，语言层盖不住）
- **治本**：把参考从 cross-attention 软条件升级为**首帧硬锚点**——分段生成，每段约 90°、用对应方向的图作为首帧，再拼接

**四、否定式指令在 H3 上不可靠**

- 实测：「不会停住、不会吸附、不要加速、不要翻滚」这类否定式惩罚**全部无效**
- 应按 H3 官方指南改为**正面陈述**：与其写「镜头保持水平不要倾斜」，不如写「地平线保持水平，墙与立柱的垂直线保持垂直，地板沿画面底部、天花板沿画面顶部」

**五、H3 连续环绕有速率上限**

- H3 官方示例写法：360° 环绕用 **15 秒**（= 24°/s），措辞为「one single continuous 360 degree orbital move, clockwise, at a slow constant rate, completing exactly one full rotation across fifteen seconds」
- 实测安全上限约 **40°/s**，超过即**翻滚**（画面倾斜、卷向天花板、地板格铺满画面）
- 完整 360° 至少需要 **9 秒 / 220+ 帧**；124 帧（5.17 秒）只容得下约 180°
- 结论：**短镜头不要要求完整 360°**——要么给足时长，要么改用多镜头硬切

**六、多视图参考的编号按「有效参考」重新计数**

- `<Picture N>` 的序号按**非空参考**从 1 连续计数，不是按 md 表的列号
- 因此参考必须**从第 1 列起连续填写**，中间留空会造成提示词编号与实际参考不符
- 关键帧视频的尾帧虽然固定填在第 9 槽，它的排位号仍是**锚点数**（非空图总数），提示词里要写 `<Picture 锚点数>` 而非 `<Picture 9>`（见技能 `stories-video-prompts` 的「关键帧视频 → 编号规则」）

**七、场景类视频的两种取法（实测取舍）**

| 方式 | 优点 | 代价 |
| :--- | :--- | :--- |
| **多镜头硬切**（OrbitSheets 默认） | 每个视角都是静止机位，**结构上不可能翻滚**；视角必然落位 | 背面/侧面是模型「编」的，可能与锚点图布局不符 |
| **单镜连续旋转** | 每帧只延续上一帧，空间关系连续 | 超过速率上限必翻滚；参考视角处吸附；长片一致性差 |

选法：**要参考板、要视角齐全 → 硬切**；**要一段连续的空间感 → 连续旋转，但必须控速在 40°/s 内、时长足够、且参考图来源一致**

**八、首帧只拍到一面墙时，背面必须有独立锚点（2026-09-27 实测）**

- **病灶**：首帧场景（I2VA）的首帧只拍得到前面墙时，若提示词把转到的 180° 反写成「后墙只由同色墙面、浅色木地板与深色天花板构成」，模型会把那一面拍成**空房**——实测 0031 旧提示词 10 秒 360°（832×480 / 243 帧）的 t=5.0s 帧是纯空墙+空地板，t=6.25s 凭空长出一张不存在的小桌与一只白色箱体，整间房在旋转中段一度变空
- **修法**：给**每面墙各钉一个独有锚点**，模型靠锚点认方位（本例 前=大窗+窗帘+书桌椅 / 右=深红棕抽屉柜+柜顶白盆绿植 / 后=一扇关着的深色木门+门框+门把手+门边开关面板 / 左=浅木框黑板+深木矮几+两盆盆栽），再写明四角以直角相接、踢脚线绕墙一圈、每件物件只经画幅左缘或右缘进出、四组锚点按前→右→后→左依次移到画幅中央
- **补的物件只挂在首帧拍不到的那面墙上**：首帧（硬锚点）已拍到的墙面一律照旧，否则与锚点图冲突（首帧里右墙后段本来就是空墙，就让它保持空）
- **复算结果**（同工作流、同首帧、仅换新提示词）：t=5.0s 得到门扇+门框+金属把手+门边白色开关面板，旋转中不再变空、不再出现新杂物，t=9.8s 构图回到 0.0s 的首帧；前后两版视频存 `backups\backup-00001_书房旋镜视频-20260927-后墙补门{前,后}.mp4`
- **边界**：门写「关着」并全程保持关着（开门会把走廊带进画面）；像素级闭环做不到，能保证的是**同一构图与同一组锚点**回到起点

**九、拍不到的墙面：房门 + 少量简单物件就够，别写成长清单（2026-09-27 实测定稿）**

- **只补门不够**：门解决了「180° 是空房」，但两侧墙后段仍是大片空白 → 四面墙都要点名，每面墙写明「拍得到的照首帧原样 / 拍不到的那一段放什么」
- **但补陈设要克制**：把整面后墙铺满（高书架+收纳盒+伞架雨伞+挂钟+矮边柜+书+茶盘茶杯+落地灯+扶手椅一组阅读角）虽然每面都有锚点、闭环也成立，但描述过长，且件数越多 H3 越容易翻倍（实测把「一张扶手椅」画成两张、挂钟被复制两处）。**定稿口径 = 每块空白墙面 1 件简单家具 + 后墙一扇门**
- **本例（书房）定稿分配**（提示词 1723 字符，比只写门的旧版 2285 还短）：右墙后段=一只木质矮书架（层板上十几本书）；左墙后段=一盆白盆绿植；后墙=中部偏右一扇关着的深色木门（门框/金属把手/木门槛/门边白色开关面板）+门左侧一只木质矮边柜（柜面一小摞书）+门右侧墙面一只圆形白色挂钟；其余墙面只写「深蓝灰墙面与深棕色踢脚线」
- **复算结果**：90°/180°/270° 每面都有实体锚点、无空墙，t=5.0s 的后墙是「矮边柜—木门—开关—挂钟」的简洁组合，t=9.9s 构图回到 0.0s 首帧；四版视频存 `backups\backup-00001_书房旋镜视频-20260927-{后墙补门后,补书房后段陈设后,座位清点后,精简陈设后}.mp4`
- **数量靠正面清单压**：需要保证"只有一件/一只"时，用正面清点句（「墙面上的挂钟只有后墙门右侧那一只」），不用否定句
- **硬约束不变**：首帧（硬锚点）里看得见的前面墙与两侧墙**前段**一律照原样，新物件只落在首帧拍不到的墙面（后墙与两侧墙后段）
- **要额外强调「只有四面墙 + 墙体无镂空」**：旋转到没拍到的区域时，模型容易自己开第二扇门/门洞/通道或把墙打穿。定稿补了两句正面陈述——「房间由四面完整的实心墙围合，一共只有这四面墙，没有第五面墙也没有隔断」+「除前面墙那扇装着玻璃、关着的窗和后墙那扇关着的木门之外，四面墙上没有门洞、拱门、通道、壁龛、窗洞、缺口或开口，每面墙都从地面到天花板连续完整，看不见墙后的任何空间；木门全程关着，门外不出现走廊」——复算后四周墙体完整连续、踢脚线不断、无多余开口（`backups\backup-00001_书房旋镜视频-20260927-强调四面墙后.mp4`）
