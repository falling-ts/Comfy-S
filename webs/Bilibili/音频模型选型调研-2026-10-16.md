# 四类音频模型选型调研 · B站 + 本地 AutoDL(2026-10-16)

调研日期:2026-10-16。目标环境:本地 AutoDL RTX 4080 32GB,ComfyUI v0.39.2(custom_nodes 47 插件 → 现 48)。

**需求**:人声 TTS、背景音乐、环境音效、效果音效 四类,取当前最流行/效果最好的模型,且本地 AutoDL 云模型库要有。

**方法**:三路并行调研(B站中文来源 + 官方 README/HF 模型卡 + GitHub API 热度),再与本地 `models/` 与云模型库清单 `webs/AutoDL/models.md`(6188 条)逐项比对。

> 数据说明:播放量为 2026-10 抓取时刻值。「B站热度」无公开榜单,B站搜索接口对部分请求需鉴权;排序为「播放量实测(音乐类) + 社区讨论密度 + 论文指标」的综合判断,非官方排名。

## 一、结论速览

**四类模型本地权重全部已就位。** 真正的缺口是**节点**——原先只有 `ComfyUI-Qwen3-TTS` 与 `audio-separation-nodes-comfyui` 两个音频插件,音乐/音效走 ComfyUI 内置节点。本轮已安装 `TTS-Audio-Suite`(人声)与 `ComfyUI-HunyuanVideo-Foley`(环境音效)补齐。

### 按用途分工

**(a) 纯器乐 BGM(无歌词)**
- 质量最强:**Stable Audio 3 Medium** — 自然语言写 `Length: 150 seconds` + BPM 控制。
- 工程最顺手(4080 首选):**ACE-Step v1.5** — 原生器乐开关、10 分钟、MIT 可商用、<4GB 显存。

**(b) 带人声完整歌曲**
- 质量天花板:**YuE2-3B** — WildSongBench best-of-8 **6.9632**,反超 Suno v5(6.8721)与 v6(6.5562);3.6 分钟歌曲 4090 仅 71 秒。
- 综合最平衡:**ACE-Step v1.5** — 质量介于 Suno v4.5~v5,A100 <2s 出全曲。

> ⚠️ **不要用 YuE2 做 BGM**:官方节点无器乐开关,`[Instrumental]` 约 20–30 秒后仍会强行起人声(社区实锤)。唯一可靠绕过是手写 ABC 乐谱把 Vocal 声部全写成休止符,成本高。
